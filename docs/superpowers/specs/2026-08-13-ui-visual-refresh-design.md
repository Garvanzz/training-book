# UI 视觉焕新：蓝调提亮配色 + 圆润几何 + 微动效语言

日期：2026-08-13
状态：已批准（用户确认）
范围：Flutter 客户端视觉层，不动业务逻辑与布局结构

## 1. 背景与目标

现状问题：石墨暗色（canvas `#0B0E12`）整体过暗过灰；圆角偏小（8–12px）观感僵硬；交互无反馈，页面"干瘪"。

目标：保留暗色主题与"安静、克制、精准"的产品基调（DESIGN.md），做到三点——更亮更透气、圆润的几何、有生命感的微动效。

## 4. 动效语言

原则：150–250ms、ease-out、只动状态变化处、不做持续装饰动画。全部使用 Flutter 内置组件，不新增动画库依赖。

1. 页面切换：全局 fade + 轻微上滑（200ms），替换默认 Material 路由过渡。
2. 桌面 hover：卡片悬停时边框提亮 + 轻微上浮（Windows 主力平台，当前悬停零反馈）。
3. 完成一组：训练页勾选时对勾图标 scale 弹入（`AnimatedSwitcher`）。
4. 进度条：训练页"x / y 组"进度条数值变化时平滑滚动（`TweenAnimationBuilder`）。
5. 按钮按压：主按钮按下轻微缩放至 0.97，松手回弹。
6. 列表出现：今日页/进度页条目首次出现淡入 + 上滑 8px（250ms，仅首次，滚动加载不重复播）。

动效时长统一为常量（如 `AppMotion.durations`），便于日后统一调整。

## 5. 实施边界与已知取舍

- 只改视觉层：主题文件 + 上述 6 处动效接入点，不重构布局、不改业务逻辑。
- 不引入任何新依赖（ponytail：Flutter 内置动画已覆盖需求）。
- 不处理系统"减少动态效果"无障碍设置（v1 个人 App，标注为已知边界；未来若上架可加 `MediaQuery.disableAnimations` 分支）。
- 明暗主题仍只有暗色一套（用户选择：暗色但更亮，不做双主题）。
