# ADR-0001：iOS + Windows 与离线优先

- 状态：已采纳
- 日期：2026-08-03

## 决策

客户端使用 Flutter，首发 iOS 与 Windows。所有训练关键路径首先写入设备本地 SQLite；服务端只在网络可用时同步，并且公共动作库使用独立的版本化发布机制。

登录是必需的。首次在线登录后，设备获得默认 30 天离线授权；授权有效时允许本地训练、计划修改和训练日志写入。

## 原因

训练常发生在网络不稳定的场地。将训练记录直接依赖网络会造成数据丢失和交互延迟。Windows 已确定为唯一桌面首发平台，因此不采用只覆盖 Apple 生态的同步方案。

## 后果

- 每项本地业务变更必须与 Outbox 操作同事务提交。
- 训练会话、计划版本和动作版本都必须保存快照，不能依赖未来的远程内容。
- 需要处理同步游标、幂等操作、软删除和冲突副本。
- iOS 构建和签名仍需要 macOS/Xcode 环境；Windows 客户端需单独完成安装包、签名和升级测试。
